# Wesnoth 1.18.x 한국어 번역 검수 이력

이 문서는 2026년 9월 24일부터 9월 26일까지 진행한 1.18.x 한국어 PO
검수의 전체 흐름과 주요 판단을 하나의 문서로 정리한 것이다. 개별 파일의
상세 변경은 같은 디렉터리의 `review-cycle-*.md` 리포트를 기준으로 한다.

## 1. 작업 기준 정리

처음에는 PO의 미번역·fuzzy 항목을 해소하고 기존 참고 번역을 활용하는 데
초점을 두었다. 이후 단순히 빈 번역을 채우는 것만으로는 기존에 잘 된
번역을 훼손할 위험이 있다는 문제가 확인되어, 다음 원칙으로 전환했다.

- 원문과 실제 게임 문맥을 먼저 확인하고 고신뢰 문제만 수정한다.
- 기존 번역이 자연스럽고 의미상 맞으면 수정하지 않는다.
- 확신이 낮거나 문맥이 부족한 항목은 보류하고 근거를 기록한다.
- 자동 일괄 치환과 용어집 전체 재적용을 금지한다.
- PO, 용어집, 태그, placeholder, 실제 개행을 함께 보존한다.
- obsolete(`#~`) 항목은 삭제하지 않고 역사 자료로 보존한다.

## 2. 2026-09-24: 기반 자료와 완료 기준 정리

영어·일본어·중국어 PO와 최신 한국어 참고 자료를 비교 기준으로 정리하고,
용어집의 구조와 감사 도구를 보강했다.

- 활성 fuzzy와 빈 번역을 미확정 상태로 간주했다.
- 복수형 `msgstr[n]`, 태그, placeholder, 개행 구조를 감사 대상에 포함했다.
- PO 원본과 작업용 PO를 분리하고, 실제 수정 위치를 `work/1.18.x/ko/`로
  고정했다.
- 용어집을 반복 용어·고유명사·게임 규칙 용어·짧은 UI 표현 중심으로
  정리했다. 긴 대사와 장문 설명은 용어집에 넣지 않는다.
- `한글(English)` 병기는 전체 gettext 문장이 아니라 실제 음차된
  고유명사 부분에만 적용하도록 정리했다.
- 복합 고유명사에서 직함·일반명사·지형 일반명사를 괄호에 넣지 않도록
  했다.
- 구조 감사와 `msgfmt --check`를 통과 기준으로 정했다. 구조 검사는
  의미 검수를 대신하지 않는다.

이 과정에서 HTTT, DID, 편집기, 도움말, fuzzy 항목 등을 번역·정리했고,
여러 PO의 미번역과 fuzzy 상태를 해소했다.

## 3. 2026-09-25: 역할과 파일 단위 업무 흐름 분리

기존 작업이 검수와 수정을 한 번에 수행하면서 같은 문제를 반복하거나
정상 번역을 변경할 위험이 있다는 판단에 따라 역할을 분리했다.

1. **검수자**: PO와 참고 자료를 읽고 문제 후보·근거·확신도·영향 범위를
   `audit/` 리포트에 기록한다. PO와 용어집은 수정하지 않는다.
2. **승인 단계**: 후보를 `수정`, `문제 없음`, `계속 보류`로 결정한다.
3. **수정자**: 승인된 항목만 수정한다. 보고서에 없는 항목은 건드리지
   않는다.
4. **검증자**: 실제 diff가 승인 범위와 일치하는지 확인하고 테스트,
   구조 감사, `msgfmt --check`를 실행한다.
5. **보고**: 파일별 변경, 보류, 용어집 영향, 검증 결과를 보고한 뒤 다음
   파일로 이동한다.

PO 하나가 끝났다고 즉시 다음 파일로 넘어가지 않는다. 해당 파일의 보류
항목과 용어집 영향 범위를 다시 확인하고, 공통 후보를 다음 파일의 검수
목록으로 이월한 뒤에만 다음 파일을 시작한다.

## 4. 2026-09-25~26: PO별 검수 사이클

도움말, 캠페인, 매뉴얼, manpage, 유닛, 멀티플레이, 라이브러리 및 각
캠페인 PO를 파일 단위로 검수했다. 각 리포트에는 대체로 다음을 기록했다.

- 고신뢰 수정 후보와 실제 수정 내용
- 기존 번역을 유지한 항목
- 근거 부족으로 보류한 항목
- 다른 PO로 이월할 공통 용어
- 테스트와 구조 검증 결과

초기 리포트에서는 장문 서술과 문장 자연스러움이 보류 목록에 남는 경우가
있었다. 이후 장문도 실제 문맥이 확인되면 검수 대상에서 제외하지 않고,
문법·의미·화자 말투를 직접 확인하는 방향으로 보완했다.

## 5. 확정된 주요 번역 규칙

### 고유명사와 병기

- 인명·지명·내부 고유명사는 한국어 음차를 우선하고 필요한 부분만
  `한글(English)`로 병기한다.
- 지명은 `카르마쓰(Karmarth) 언덕`, `텔파르(Telfar) 강`처럼 고유명사
  부분만 병기한다.
- 직함·호칭·일반명사는 고유명사 괄호에 넣지 않는다.
- `Sir Wose`는 인명이 아니라 Wose족을 높여 부르는 호칭으로 보아
  `워즈(Wose) 경`으로 처리한다.
- `Mal Ravanal`은 `말-라바날(Mal-Ravanal)`로 정식 표기를 통일한다.
- `Estmark`는 `에스트마르크(Estmark)`로 음차·병기한다.

### 종족과 생물명

- `Elf/Elves`는 `엘프/엘프들`로 통일한다.
- `faerie`는 `요정`, `faerie fire`는 `요정 불꽃`으로 번역한다.
- `Wose/Woses`는 `워즈(Wose)/워즈들(Woses)`로 처리한다.
- 종족명 영어 복수형은 한국어도 `들`로 표시한다. `족`을 복수형 표지로
  사용하지 않는다.
- `Saurian/Saurians`는 `사우리안/사우리안들`이다.
- `Lizard/lizard`는 일반 동물명·유닛명 문맥에서 `도마뱀`으로 처리하며
  `Saurian`과 섞지 않는다.
- `Wyrm`은 일괄 치환하지 않는다. 중립적 생물명·유닛명은 `웜(Wyrm)`,
  `웜`, 또는 문맥상 `뱀룡`을 사용한다.
- `wyrm`이 다른 생물을 낮춰 부르는 멸칭이면 문맥에 따라 `도마뱀/도마뱀들`
  을 사용할 수 있다.
- `Wyrms of Khrakrahs`는 멸칭이 아니라 고유 진영·생물 집단명으로
  `크흐라크라흐스(Khrakrahs) 뱀룡`을 사용한다.

### 게임 규칙과 UI

- `heal/healing`은 HP 회복 의미의 `회복`이다.
- `cure`는 독이나 상태 이상 제거 의미의 `치료`이다.
- `Always rest heals`는 행동하지 않고 휴식할 때의 효과를 나타내므로
  `상시 휴식 회복`으로 처리한다.
- `Frozen terrain`은 지형 문맥에서 `얼음 지형`으로 처리한다.
- 상태값 `Frozen`과 지형 표현은 같은 번역으로 자동 통일하지 않고 문맥을
  확인한다.

## 6. 현재 검수 상태

현재까지의 검수는 다음 단계까지 진행되었다.

- PO별 감사 리포트와 전역 용어 리포트가 `work/1.18.x/audit/`에 축적됨
- 용어집에 고유명사·복수형·문맥별 예외가 반영됨
- `Saurian`, `Wyrm`, `Wose`, `Elf/faerie` 전역 재검토가 수행됨
- 활성 PO 구조, placeholder, 태그, `msgfmt` 검증을 반복 수행함

다만 이 문서는 과거 결정을 회수한 통합 이력이다. 이후 새 판단이 생기면
다음 세 곳을 함께 갱신해야 한다.

1. 이 문서의 해당 규칙 또는 날짜별 이력
2. 반복 용어이면 `glossary.tsv`의 표준값과 `notes`
3. 특정 PO에서 나온 판단이면 해당 `review-cycle-*.md` 리포트

통합 이력과 개별 리포트의 내용이 충돌하면, 실제 영어 원문과 해당 PO의
문맥을 다시 확인한 뒤 용어집을 수정한다. 용어집은 불변의 진실이 아니다.
