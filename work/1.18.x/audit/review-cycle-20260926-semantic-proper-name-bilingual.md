# Review Cycle 2026-09-26: 의역된 고유명사 병기

## 결정

고유명사를 한국어에서 의미 중심으로 의역해도, 게임 세계 안에서 특정
인물·세력·지역·종족·유닛을 가리키는 이름이면 `의역어(원문)`으로 병기한다.
병기 여부는 음차인지 의역인지가 아니라, 번역으로 원문 식별 정보가
사라지는지를 기준으로 판단한다.

## 예시

- `Clearwater` → `맑은물(Clearwater)`
- `Blackwater` → `검은물(Blackwater)`
- `Slowhand` → `느린손(Slowhand)`
- `Wesfolk` → `서부인(Wesfolk)`

## 예외

- 일반 표현인 `clear water`는 `맑은 물`로 번역하고 병기하지 않는다.
- 작품명·캠페인 제목은 자연스러운 한국어 제목과 기존 정착 표기를
  우선하며, 제목별로 병기 여부를 별도 판단한다.
- 고유명사성이 확인되지 않은 후보는 자동 병기하지 않고 감사 대상으로
  남긴다.

## 반영

- `work/1.18.x/TRANSLATION-RULES.md`에 일반적인 의역 고유명사 병기
  규칙과 예외를 추가했다.
- 기존 `glossary.tsv`의 개별 표기와 충돌하지 않도록, 실제 PO 문맥에서
  고유명사 여부를 확인한 뒤 개별 항목을 갱신한다.
