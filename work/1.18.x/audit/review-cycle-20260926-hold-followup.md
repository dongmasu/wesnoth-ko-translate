# 2026-09-26 보류·이월 항목 최종 분류

## 범위

이전 PO별 감사 리포트의 `보류`, `보류 및 이월` 항목을 다시 수집하고,
실제 영어 원문과 현재 한국어 PO 문맥을 대조했다. 이번 단계에서는 보류
항목의 분류만 수행했으며, 근거가 부족한 항목을 추측으로 수정하지 않았다.

## 최종 분류

| 범주 | 대상 | 판정 | 조치 |
|---|---|---|---|
| EI 배율 UI | `wesnoth-ei-ko.po:35-56`, `1x/3x/5x enemies` | 현재 `적 1배`, `적 3배`, `적 5배`는 의미를 전달한다. `배수`를 추가하면 UI 폭과 기존 선택지 문체를 확인하지 않은 상태에서 불필요한 변경이 된다. | 계속 보류 |

## 장문 서술의 재검토 기준

다음 항목은 이번 단계에서 보류로 남겼다.

- 원문의 의미를 훼손하지 않는 화자별 방언·말투와 의도적인 비문
- 동일한 의미를 유지하는 문체·어휘 선호 차이
- 앞뒤 대사나 실제 화면을 추가로 확인해야만 결정할 수 있는 낮은 확신의 표현
- obsolete 항목

반대로 주어·행위·인과관계가 바뀌거나, 정보가 누락·추가되거나, 명백한
오탈자·띄어쓰기·구조 오류가 확인되는 장문은 보류 대상이 아니며 해당
PO별 리포트에서 이미 수정했거나 다음 고신뢰 사이클의 수정 후보로
기록한다.

## 결론

EI와 Editor 보류 항목에는 새로 확정할 고신뢰 수정이 없었다. 다만 장문
서술 재검토에서 의미 누락·유닛명 오역·명백한 오타·문장 구조 파손이
확인된 7건은 `wesnoth-utbs-ko.po` 6건과 `wesnoth-l-ko.po` 1건을
수정했다. 나머지 장문은 보류 항목으로 유지한다.
