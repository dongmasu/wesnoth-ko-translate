# Wesnoth 1.18.x Work

이 디렉터리는 실제 Wesnoth 1.18.x 한국어 번역 작업 공간입니다.

## 디렉터리

```text
work/
└── 1.18.x/
    ├── README.md
    ├── glossary.tsv
    └── ko/
        └── *.po
```

- `ko/`: 실제로 수정하고 검토하는 한국어 PO 파일
- `glossary.tsv`: 번역 용어, 일본어·중국어 참고 표현, 의미 분류와 근거를 기록하는
  용어집
- `po/1.18.x/`: 수정하지 않는 locale별 PO 원본 스냅샷
- `References/`: 과거 번역 자료와 참고 문서
- `tests/`: PO 파일 구조와 문법을 검사하는 프로젝트 테스트

작업을 시작할 때 `References/20250322_wesnoth_한국어번역/`의 최신 한국어
PO를 먼저 검토하고 가능한 한 적극적으로 활용한 뒤 `ko/`에서 작업합니다.
다만 현재 영어 원문·게임 문맥·태그·placeholder와 충돌하면 근거를 남기고
조정합니다. 원본 locale과 비교할 때는
`po/1.18.x/ja/`, `po/1.18.x/zh_CN/`, `po/1.18.x/en_GB/`를 사용합니다.

`glossary.tsv`에 기록된 항목은 번역자가 누구든 동일하게 사용해야 하는 표준
번역입니다. 과거 카페 표현과 대안은 용어집의 `forbidden_terms` 또는
`References/wesnothko/translation-notes.tsv`에 보존하며 표준 번역으로
사용하지 않습니다.

용어집은 반복되는 명사·동사·형용사·고유명사와 짧은 고정 UI 표현을 위한
파일입니다. 특정 대사나 긴 설명문 전체를 용어집에 넣지 않습니다. 도구
이름은 원문을 유지하므로 `wmllint`는 `wmllint`, `wmllint mode`는
`wmllint 모드`로 기록합니다.

`glossary.tsv`의 `category` 열은 gettext의 `msgctxt`를 뜻하지 않습니다.
파일 호환성을 위해 유지하는 의미 분류 열이며, 병기 여부를 결정하는
판정 기준으로 사용하지 않습니다. 병기는 각 행의 영어 원문과 한국어를
직접 대조해 실제 음차된 부분에만 적용합니다. `^`가 포함된 짧은 문맥
키는 분류상 `contextual`로 기록할 수 있지만, 이 분류로 병기하지 않습니다.

## 현재 검증 기준

2026-09-24 현재 작업 PO는 활성 fuzzy 0개, 활성 비-fuzzy 빈 번역 0개,
빈 복수형 0개를 목표 기준으로 관리합니다. 여기서 활성 항목은
`msgid ""` 헤더와 `#~` obsolete 항목을 제외한 메시지입니다. `#, fuzzy`가
붙은 항목은 `msgstr`가 채워져 있어도 미확정으로 세며, 복수형은 모든
`msgstr[n]`이 채워져야 완료입니다.

문서만으로 감사할 때는 다음을 순서대로 실행합니다.

```sh
python3 -m unittest discover -s tests -v
python3 tools/audit_po_structure.py
for po in work/1.18.x/ko/*.po; do
    untranslated="$(
        msgattrib --untranslated --no-fuzzy --no-obsolete "$po" |
        awk '$1 == "msgid" { count++ } END { print count + 0 }'
    )"
    fuzzy="$(
        msgattrib --only-fuzzy --no-obsolete "$po" |
        awk '$1 == "msgid" { count++ } END { print count + 0 }'
    )"
    printf '%s untranslated=%s fuzzy=%s\n' "$po" "$untranslated" "$fuzzy"
done
find work/1.18.x/ko -name '*.po' -print0 |
  xargs -0 -n1 msgfmt --check --output-file=/dev/null
```

정상 결과는 테스트 성공, 모든 파일의 `untranslated=0`과 `fuzzy=0`,
`markup_mismatches=0`, `placeholder_mismatches=0`입니다. `msgfmt`의
헤더 기본값 경고는 종료 코드 실패와 다르므로 별도 기록합니다. 용어집
검사는 테스트가 수행하며, `source_term` 중복·숫자 단독 항목·금지 대안
충돌·용어집과 PO의 한국어 불일치·`^` 문맥 접두사 누출을 포함합니다.

## 배포와 태그

PO는 작업·배포 원본이고, 실제 게임에는 `msgfmt`로 생성한 MO를 설치합니다.
운영체제별 경로와 변환 명령은 프로젝트 루트의 [INSTALL.md](../../INSTALL.md)에
기록되어 있습니다. 1.18.x 번역 완료 후에는
`wesnoth-ko-translate-1.18.x-<최종수정일>` 형식의 annotated tag를 만듭니다.
`<최종수정일>`은 KST/JST 기준 마지막 PO 수정일(`YYYYMMDD`)이며, 카페 HTML 보관본을
공개 저장소에 포함하지 않았는지 확인한 뒤 push합니다.


작업 후 프로젝트 루트에서 다음 검사를 실행합니다.

```sh
python3 -m unittest discover -s tests -v
```
